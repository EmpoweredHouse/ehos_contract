# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

It applies in the repository's issues and pull requests, and wherever someone represents the
project.

To report behaviour that breaks it:

- **Something that can be discussed in the open**, such as a thread that has turned hostile, goes in an issue.
- **Anything about a particular person** goes through GitHub's **Report content**, in the `...` menu of the
  comment, issue or pull request concerned. Choose to report it to the repository's maintainers. Only they see
  it; it does not appear in the thread, and the person reported is not told who reported it.

The maintainers read every report, answer the one who made it, and keep reports confidential.
